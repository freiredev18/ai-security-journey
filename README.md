# ai-security-journey

I'm a backend developer from Brazil (Python, SQL, PostgreSQL) learning offensive security — with a focus on breaking AI and LLM applications. This repo is my notebook, kept in public.

I started on November 3, 2026, almost from zero. I know some terms, I've read some stuff, but I've never really done this. So instead of studying quietly and showing up "ready" one day, I decided to write down everything I solve, as I go.

Every week I solve labs and challenges, write up what I learned, and publish it here. Fridays I also post a video and a short summary on LinkedIn.

## What you'll find here

Writeups. Not copy-paste solutions — each one tries to explain *why* the attack works, what the real impact is, and how a developer should fix it. That last part matters to me: I come from the side that writes the code, and I want to keep thinking like someone who has to defend it too.

## The plan (first 3 months)

- Web security fundamentals — PortSwigger Web Security Academy and TryHackMe
- The OWASP Top 10 for LLM Applications
- Prompt injection, jailbreaks, RAG and agent attacks
- AI red teaming challenges on Gray Swan Arena and Lakera Gandalf

## A note on ethics

Everything here comes from intentionally vulnerable labs, CTFs, or programs that explicitly allow testing. I don't test systems without permission, and I don't publish details about real bugs until they're fixed and the program allows it.
